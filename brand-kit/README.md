## The five rules that matter

1. Clear space is half a mark-width on every side. Nothing enters it.
2. Minimum size: 24px is comfortable, 16px is the floor, 6mm is the engraving floor.
   Below 24px use siumora-mark-small-size.svg — thicker stroke, larger kernel.
3. Brass is a foil, a stroke or a kernel. Never a large fill, never a gradient.
4. One accent per view. Mulberry does the work; the page is ink on ivory.
5. Never place the logo on top of the pattern — the pattern is what the logo is made of.

## Type

Cormorant Garamond Light 300 (display + wordmark) · Marcellus (secondary caps) ·
Jost 300/500 (interface and body). All free from Google Fonts — see 03-colour-type/fonts.md.

## Voice

Say: "Something given, something kept." · "Every piece leaves here wrapped as a gift."
Never say: bridal, trousseau, dowry, investment, luxury, exclusive, premium,
treat yourself, girl boss — or anything implying she needs permission.

## A note on the SVG lockups

The lockups set SIUMORA as live text in Cormorant Garamond. Install the font (free,
Google Fonts) before opening them, or convert text to outlines in Illustrator/Figma
before sending to a printer.
