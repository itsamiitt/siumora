# Motion

siumora-logo-sting.html — the brand sting, 1280x720.

Open it in a browser. Scene timing is editable on the timeline; use the export control
to render video. Four scenes: the lattice, the chosen cell, the mark being set, the sign-off.

Motion principles: circles always arrive from their own axis, the kernel always lands last
and rings once, the wordmark always tracks in from wide to 0.34em. Nothing rotates but the
polish sweep. Never bounce the wordmark.
