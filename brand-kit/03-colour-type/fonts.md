# Siumora typefaces

All three are Google Fonts — free for commercial use, no licence to purchase.

| Role | Family | Weights | Link |
| --- | --- | --- | --- |
| Display / wordmark | Cormorant Garamond | 300, 400 | fonts.google.com/specimen/Cormorant+Garamond |
| Secondary heading | Marcellus | 400 | fonts.google.com/specimen/Marcellus |
| Interface / body | Jost | 300, 400, 500 | fonts.google.com/specimen/Jost |

Web embed (one line, all three):

    <link href="https://fonts.googleapis.com/css2?family=Marcellus&family=Cormorant+Garamond:wght@300;400&family=Jost:wght@300;400;500&display=swap" rel="stylesheet">

Wordmark setting: Cormorant Garamond Light 300, all caps, letter-spacing 0.34em with an
equal left padding so the word stays optically centred. Never bold, never italic, never condensed.
